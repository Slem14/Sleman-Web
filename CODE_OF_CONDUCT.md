# Code of Conduct

This project serves vulnerable people navigating German bureaucracy. Everyone participating in it — contributors, reviewers, testers — is expected to act accordingly:

- Be respectful; no harassment, discrimination, or derogatory language.
- Treat user trust as sacred: never mock, share, or speculate about the situations of people who use the product.
- Language communities are partners, not resources: native reviewers' judgments about their own language are respected.
- Disagreements are resolved with arguments and evidence, not authority or volume.

Based on the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/) v2.1. Concerns: parwizsleman@gmail.com.
